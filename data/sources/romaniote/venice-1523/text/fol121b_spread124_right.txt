תפלות של פסח
זולת
אהבוך נפש להודך ˙ מזנים בוטח ושודך ˙ אנה הלך דודך :
בשוב נוחך גנונו ˙ רבבה תרנן בגינו ˙ דודי ירד לגנו :
גשים נבנה בהחדילי ˙ דוברים נלכה להבדילי ˙ אני לדודי ודודי לי :
דמני נאה ותרוצה ˙ כנני בלא פרצה ˙ יפה את רעיתי כתרצה :
הזהירני ממעש מעניך ˙ התעב גיא כנעניך ˙ הסבי עיניך :
ועמך כלם הלולים ˙ קדש ולא חולים ˙ שניך כעדר הרחלים :
זבדני זבול ארמון ˙ טייב יושבי אמון ˙ כפלח הרמון :
חכמי מלאכות מלכות ˙ נצח עולם הליכות ˙ ששים המה מלאכות :
טוענים אסופות גנתי ˙ יחד נוטעים כנתי ˙ אחת היא יונתי תמתי :
יושרם יליץ התקפה ˙ גבהות קרן זקופה ˙ מי זאת הנשקפה :
כעס ושחוק יגוז ˙ דלת ראש מלגוז ˙ אל גנת אגוז :
לגולל אבן צמתני ˙ באר חיי צימתני ˙ לא ידעתי נפשי שמתני :
מתי לחציר נעמית ˙ תועה ומתעה להעמית ˙ שובי שובי השולמית :
נעים התנדב מעולים ˙ ראות ולקלם מועלים ˙ מה יפו פעמיך בנעלים :
סדר עבודת כהונן ˙ השב בשיתו נוגן ˙ שררך אגן :
ערוך אילים ופרים ˙ כאז ביד סופרים ˙ שני שדייך כשני עפרים :
פתח שיר מלדל ˙ הדר זוקן מגודל ˙ צוארך כמגדל :
צו חסד גומל ˙ ונשא כאמור חומל ˙ ראשך עליך ככרמל :
קשט תטור אשמת ˙ גנאי זכרונך שמת ˙ מה יפית ומה נעמת :
ריב לטוב יומר ˙ ולשפלת עמק יזומר ˙ זאת קמתך דמתה לתמר :
שטף בכל משמר ˙ כלם קדושים במאמר ˙ אמרתי אעלה בתמר :
תען דבר טוב ˙ שורה אחת לחטוב ˙ וחכך כיין הטוב :
שחורה ונאוה תשוקתו ˙ לא מרוב חשוקתו ˙ אני לדודי ועלי תשוקתו :
מחפורים שור ספורים ˙ הסתכל בך כופרים ˙ לכה דודי נצא השדה נלינה בכפרים :
בינה רצוי תורמים ˙ בסוס עולם גורמים ˙ נשכימה לכרמים :
יותן קול צורח ˙ הטובות והרעות הפרח ˙ הדודאים נתנו ריח :
דודי נוח לי ˙ תנחמני ומוחל לי ˙ מי יתנך כאח לי :
חזות כאז צבאך ˙ זוהר שכינת מראך ˙ אנהגך אביאך :
קירובך עם דבקני ˙ וסת שבחך ספקני ˙ שמאלו תחת לראשי וימינו תחבקני :
אחרית לטהר שולים ˙ מהר לשלש בכפלים ˙ השבעתי אתכם בנות ירושלם :
